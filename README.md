# Madadgar 🇵🇰

**Public Service Information Resource for Pakistani Citizens**

**Repository:** [https://github.com/kasaam-ali/Madad-Gar](https://github.com/kasaam-ali/Madad-Gar)

Madadgar is an authoritative, clean, and high-trust digital portal designed to streamline interactions with public administration in Pakistan. It eliminates dependency on middlemen and unauthorized agents by providing verified documentation checklists, official fee schedules, and clear procedural workflows.

---

## 🏛️ Services Covered

1. **National Identity Card (CNIC / Smart NIC)** — NADRA (Fresh Registration, 10-Year Renewal, Modifications)
2. **Machine Readable & e-Passport** — Directorate General of Immigration & Passports (DGIP)
3. **Driving License (Learner & Permanent)** — Provincial Traffic Police (Punjab, Sindh, KP, ICT, Balochistan)
4. **Domicile & Permanent Residence Certificate (PRC)** — District Administration / DC Office
5. **FBR NTN & Active Taxpayer List (ATL)** — Federal Board of Revenue IRIS Portal
6. **Child Registration Certificate (CRC / Form-B)** — NADRA & Local Union Councils
7. **Police Character Certificate** — City Police & Police Khidmat Markaz
8. **New Electricity Connection** — DISCOs (LESCO, IESCO, K-Electric, MEPCO, PESCO, GEPCO)

---

## ✨ Features

- **100% Professional English** — Formatted according to official departmental nomenclatures.
- **Pure Vector Icons (Zero Emojis)** — Clean SVG icons for high credibility and civic authority.
- **Light & Dark Theme Toggle** — Seamless switching with persistent storage.
- **Interactive Document Checklists** — Check off items as you gather them, with real-time readiness progress tracking.
- **Printable Dossier Feature** — One-click clean print stylesheet for physical office visits.
- **Instant Search & Category Filters** — Real-time filtering across titles, authorities, and keywords.
- **Verified Official Fee Schedules** — Clear breakdown of normal, urgent, and executive fees in PKR.
- **Direct Official Portals & Helplines** — Direct verified links to official `.gov.pk` portals.
- **Zero Framework Bloat** — Pure HTML5, Vanilla CSS, and lightweight JS with 0 build steps.

## 🚀 Quick Start (Local Development)

```bash
# Clone the repository
git clone https://github.com/kasaam-ali/Madad-Gar.git
cd Madad-Gar

# Start local preview server
npm run dev
# Server will be live at http://127.0.0.1:3000
```

2. Select your GitHub repository `kasaam-ali/Madad-Gar` and click **Deploy**.

### Deploy on Netlify
1. Log in to [Netlify](https://app.netlify.com).
2. Connect your GitHub repository `kasaam-ali/Madad-Gar` or drag-and-drop the directory.
