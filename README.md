## 🎯 The Problem It Solves

In Pakistan, getting basic citizen documentation—whether obtaining a **CNIC**, renewing an **International Passport**, applying for a **Driving License**, or becoming an **FBR Tax Filer**—is often plagued by:

- ❌ **Unregulated Commission Agents & Middlemen** charging 5x–10x official rates.
- ❌ **Multiple Office Trips** due to missing a single obscure photocopy or affidavit.
- ❌ **Zero Transparent Information** on real government fee schedules and timelines.

### 💡 The Solution: Madadgar
**Madadgar** provides a centralized, high-trust, and 100% free digital directory. Citizens get:
1. ✅ **Interactive Checklists** — Track required vs optional documents before leaving home.
2. ✅ **Official Fee Schedules** — Clear breakdown of Normal, Urgent, and Executive rates in PKR.
3. ✅ **Step-by-Step Procedure** — Clear, verified stages from token generation to card delivery.
4. ✅ **Printable A4 Dossier** — 1-click printout formatted specifically for physical office visits.

## 🚀 Local Setup & Development

### 1. Clone the repository
```bash
git clone https://github.com/kasaam-ali/Madad-Gar.git
cd Madad-Gar
```

### 2. Run locally
Since there are no heavy node dependencies or build steps, you can open `index.html` directly in your browser, or start a local dev server:

```bash
# Using npm script
npm run dev

# Or using Python 3
python -m http.server 3000
```
Open **`http://localhost:3000`** in your browser.

## 🛡️ Citizen Rights & Anti-Fraud Advisory

1. 🚫 **Never hand over original CNICs or Passports** to unauthorized middlemen standing outside government offices.
2. 💳 **Use Electronic PSID Payments** directly through official banking apps (1Link / e-Pay) whenever possible.
3. 🧾 **Always demand computerized machine-printed receipts** with official tracking numbers.
